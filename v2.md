# Rencana Migrasi Homepage (Halaman /v2)

Berikut adalah susunan kerja (rencana) untuk memigrasikan `homepage-orangetrail/index.html` ke dalam proyek utama kita sebagai halaman `/v2`.

## 1. Analisis Struktur HTML Saat Ini
- [x] Membaca dan menganalisis kode pada `homepage-orangetrail/index.html`.
- [x] Mengecualikan (exclude) bagian header/navbar dan footer dari file lama tersebut. Kita hanya akan mengambil bagian *content/body* (section-section utamanya saja).

## 2. Pemindahan dan Penataan Aset (Images, CSS, JS)
- [x] Mengidentifikasi seluruh aset (gambar, ikon, stylesheet, atau script) yang secara aktual **dipakai** di dalam `index.html`.
- [x] Menyalin aset-aset yang dipakai tersebut dari `homepage-orangetrail/assets` ke dalam proyek utama. Agar rapi dan tidak bentrok dengan aset lama, kita bisa menaruhnya di dalam folder spesifik seperti `public/assets/v2/` atau `src/assets/v2/`.
- [x] Meninggalkan aset-aset yang tidak dipakai (unused).

## 3. Pembuatan Halaman Astro (`/v2`)
- [x] Membuat file halaman baru sesuai struktur Astro yang sudah ada, yaitu `src/pages/v2.astro` (atau `src/pages/v2/index.astro`).
- [x] Menggunakan layout utama proyek (misal `<BaseLayout>`). **Sangat Penting: Header dan Footer mutlak mengambil dari file komponen yang sudah ada di proyek, bukan membuat ulang atau menyalin dari file lama**.
- [x] Menyalin struktur HTML (khusus bagian konten/section, tanpa header & footer lama) dari `index.html` ke dalam layout di file `.astro` tersebut.

## 4. Penyesuaian Path Aset dan Styling
- [x] Mengubah seluruh tautan (path) aset di dalam file `.astro` yang baru. Misalnya, dari `<img src="./assets/gambar.jpg">` menjadi `<img src="/assets/v2/gambar.jpg">`.
- [x] **Adaptasi Styling Global:** Mengganti class CSS bawaan file lama agar **menyamai style di homepage utama proyek saat ini**. Ini mencakup:
    - [x] Penggunaan jenis font (typography)
    - [x] Warna dan desain tombol (button styling)
    - [x] Warna teks, ukuran font, margin, dan padding
- [x] Tujuannya agar halaman `/v2` terlihat menyatu dan konsisten dengan desain sistem web kita, bukan desain web lamanya.

## 5. Pengujian & Verifikasi (Quality Assurance)
- [x] Mengecek tampilan di browser melalui dev server (`npm run dev`) pada URL `/v2`.
- [x] Memastikan bahwa tampilannya sama persis (pixel-perfect) dengan versi HTML aslinya, atau sesuai dengan desain yang telah diadaptasi.
- [x] Memastikan semua gambar berhasil dimuat (tidak ada broken image) dan fitur interaktif berjalan normal.

## 6. Pembersihan (Cleanup)
- [ ] Setelah halaman `/v2` dipastikan 100% jalan dan mandiri (sudah menggunakan aset di folder proyek).
- [ ] Kita menghapus folder `homepage-orangetrail/` beserta seluruh isinya secara permanen agar proyek tetap bersih.
